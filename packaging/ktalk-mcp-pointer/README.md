# ktalk-mcp — переехало в `ktalk-cli`

Этот пакет больше не развивается. Продукт переехал в дистрибутив
[`ktalk-cli`](https://pypi.org/project/ktalk-cli/) начиная с версии `1.0.0`.

```bash
uv tool install ktalk-cli
```

## Что изменилось

Пакет был двухголовым: MCP-сервер и CLI-реестр записей Контур.Толк под одним
именем. MCP-поверхность снята целиком, зависимость `fastmcp` убрана — остался
CLI `ktalk`, тот же по составу команд. Имя пакета перестало соответствовать
содержимому, поэтому дистрибутив переименован.

**Имя команды не изменилось.** Как было `ktalk`, так и осталось.

## Если старый пакет ещё установлен

Два пакета не могут владеть одним именем команды: установка `ktalk-cli` откажет,
пока `ktalk-mcp` занимает слот.

```bash
uv tool uninstall ktalk-mcp
uv tool install ktalk-cli
```

Эта версия команду `ktalk` не предоставляет — только `ktalk-mcp`, которая
печатает это же сообщение и завершается ненулевым кодом.
