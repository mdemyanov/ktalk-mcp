# Lessons learned

Append-only журнал. Новая запись — вниз, старые не редактируются и не удаляются.

## 2026-08-13 — гейт нельзя включать раньше контура

`/nauta:sync-scripts` доставляет `scripts/` и `.githooks/pre-commit`, но `validate-content.py`
возвращает код 2 на отсутствующем каталоге `content/` — не skip, а ошибку. В код-проекте без
контура активация хука сразу после синка заблокировала бы каждый `git commit`.

**Правило:** после синка сначала холостой прогон `bash scripts/check.sh --fast`, и только при
`Errors: 0` — `bash scripts/install-hooks.sh`. Порядок обратный интуитивному «поставил хук,
дальше разберусь».

## 2026-08-13 — пороги гейтов копировать из шаблона нельзя

Шаблонные `qualityThreshold` (100–200 строк) на этом корпусе недостижимы для тестов: максимум
top-level декларации в тестах — 109 строк. Скопированный порог дал бы гейт, который выглядит
включённым и молчит всегда — худший исход, чем выключенный гейт: он создаёт ложную уверенность,
что «нарушений нет», хотя на деле «не проверялось».

**Правило:** перед включением любого порога — замер по репозиторию, результат в
companion-спеку ([ADR-001 spec](40-architecture/ADR-001-nauta-contour-spec.md)).

## 2026-08-13 — гейт кода не отличает свой код от вендоренного

Пороги C13 калибровались, когда `scripts/` ещё были untracked. После `git add scripts/` тот же
гейт заблокировал коммит на `_drift_check.py` и `validate-profile.py` — это payload плагина,
приезжающий синком, а не наш код: расщепить его нельзя, следующий `/nauta:sync-scripts`
перезапишет правку. Исключения по пути C13 не поддерживает — только пару `extension`+`kind`.

**Правило:** калибровать пороги C13 на той популяции файлов, которая будет **под git после
коммита**, а не до него — `git ls-files` не видит untracked. Вендоренный payload заносится в
`sizeBudgetGrandfathered` отдельным блоком с комментарием «не наш долг», иначе через полгода
никто не отличит замороженный чужой файл от собственного отложенного рефакторинга.
