# Онбординг плагина ktalk — обнаружение зависимости и санкционированная установка — переехало

Требование переехало в репозиторий плагина `ktalk-plugin`, файл
`content/30-requirements/2026-08-18-onboarding-sanctioned-install.md`.

**Причина.** Предмет требования — плагин, а не пакет: разведение проведено по предмету,
а не по имени файла (ADR-023 в дереве плагина, санкция владельца на гейте `gate-ba`
эпика `ktalk-plugin-56l`). Пара дрейфа объявлена там же — `plugin-onboarding-sanctioned-install`.

**Почему файл остался здесь.** Требование цитируется 34 ссылками из 22 документов этого
дерева — пяти ADR, роадмапа, спек-компаньонов, security-review и заметок Dev. Все они
исторические: решение принималось *против* этого требования, и запись «решено против
чего-то, чего нет» была бы ложью об истории. Указатель сохраняет след, не переписывая
закрытые документы. Тот же приём, каким пакет `ktalk-mcp` уступает имя пакету `ktalk-cli`.

Содержания здесь больше нет — оно целиком по адресу выше.
