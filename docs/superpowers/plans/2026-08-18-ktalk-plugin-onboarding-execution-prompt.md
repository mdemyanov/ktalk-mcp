плагин собран и опубликован в `https://doc-hub.gitlab.yandexcloud.net/tools-ai/ktalk-plugin`
(рабочая копия — `/Users/mdemyanov/Devel/ktalk-plugin`, отдельный git-репозиторий). Волна 4 даёт
плагину право обнаруживать отсутствие пакета, помогать его установить и — по явной санкции —
устанавливать самому.

Все архитектурные развилки закрыты владельцем 2026-08-18 и перечислены в разделе Global Constraints
плана. Они не пересматриваются: субагент, который считает решение неоптимальным, реализует его как
записано и пишет возражение в отчёт.

  публичный. Фикстуры — синтетические.

- **`git push` не выполнять ни в одном из двух репозиториев.** Коммиты — да, push — мой.

  терминале — мои операции. Не эмулировать TTY через `script`/pty ради тестов `grant`: это обошло
  бы барьер, который тест и защищает.
- Гейты перед сдачей: `uv run pytest` зелёный, `uv run ruff check .` без новых ошибок (36
  существующих в `scripts/validate-profile.py` — не ваши), `bash scripts/check.sh --fast`
  → `Errors: 0`. В репозитории плагина: `bash scripts/test-onboard.sh` → `FAIL: 0` и
  `bash scripts/check-plugin-composition.sh` → код 0.
- Расхождения реализации со спекой — дев-заметкой в `content/60-implementation/` с причиной
  (Task 8), не молча.
- Стиль всех текстов (коммиты, статьи, сообщения скрипта): сухо и сжато, по-русски.
